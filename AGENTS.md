# Правила работы с BranchDock

## Обновление приложения

При каждом изменении приложения необходимо обновлять готовую macOS-сборку вместе с исходниками и отправлять изменения в GitHub (`origin`). Это постоянное пожелание владельца проекта.

1. Выполнить проверки, соответствующие изменениям, и собрать приложение командой `./build-app.sh --no-install`.
2. Упаковать актуальный `dist/BranchDock.app` в ZIP в папке `downloads` через `ditto -c -k --sequesterRsrc --keepParent`. Готовая сборка хранится прямо в репозитории; GitHub Releases для неё не использовать.
3. Пересчитать `downloads/SHA256SUMS.txt`, проверить распаковку архива и подпись приложения (`codesign --verify --deep --strict`).
4. Если версия, архитектура или имя архива изменились, обновить ссылки и требования в README. Имя архива должно соответствовать версии приложения.
5. Закоммитить исходники, актуальный архив, контрольную сумму и изменения документации; выполнить push в GitHub. Не оставлять опубликованную сборку от предыдущей версии исходников.

Для изменений только документации пересборка приложения не требуется. При ошибке сборки или push сообщить о проблеме и не выдавать обновление за опубликованное.
